Zoho Off-Campus Developer Drive

B.Tech Mechanical (Self-Taught Coder)
Round 1 & 2: Basic C Output prediction with tricky pointers, followed by 5 coding problems (string reversal without library functions, matrix spiral print).
Round 3 (Mini-App Development): Built a console-based Railway Ticket Reservation system in Java in 2.5 hours. Handled waiting list priority queues and seat cancellations.
